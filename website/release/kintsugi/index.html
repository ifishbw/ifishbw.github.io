Camera System

My design goals I was able to achieve for the camera system I developed:

  • Robust enough that the player would never have to control the camera manually.
  • Smooth enough that people who get motion sick would have no issues.
  • Allow for easy implementation of level tools to enable further control of the camera.
  • Designed for the controller experience.

A lot of the design was based on a GDC talk by the game-feel engineer for Journey.

Movement System

During development I took over the movement system and implemented:

  • Refactored all the code into a State Machine.
  • Implemented the swoop and mantle mechanics.
  • Worked on improving game feel.
